# Tecnologías del proyecto — [Altima.StR]

> Guía: [Tecnologías del proyecto](../evaluacion/guias/fase-1-requerimientos/04-tecnologias.md)

### Stack

| Área | Herramienta | Para qué la uso |
|---|---|---|
| Construcción | HTML + CSS | Crear la estructura del sitio web, diseñar el catálogo de gorras y definir la identidad visual de altima.str. |
| Versionado | Git y GitHub | Guardar los cambios del proyecto, mantener un historial de versiones y trabajar de forma organizada. |
| Publicación | GitHub Pages | Publicar el sitio web para que los usuarios puedan visitarlo mediante un enlace público. |
| Diseño | Whimsical | Organizar la estructura del sitio, crear mapas de navegación y planificar la experiencia del usuario. |
| Diseño | Google Stitch | Explorar propuestas visuales para la tienda, definir la distribución de las páginas y generar referencias para el diseño de la interfaz. |
| IA | ChatGPT y Claude | Apoyar la planificación del proyecto, redactar textos comerciales, definir funcionalidades y resolver dudas durante el desarrollo. |
| Editor | Visual Studio Code | Escribir, organizar y editar el código HTML y CSS del sitio web. |

## Qué es funcional y qué es prototipo

| Funcionalidad | Estado en esta versión |
|---|---|
| Visualización de la página de inicio y presentación de altima.str | Funcional si está implementada en HTML y CSS |
| Navegación entre secciones del sitio | Funcional si los enlaces están implementados correctamente |
| Visualización del catálogo de gorras | Funcional como catálogo visual |
| Visualización de fotografías, nombres y precios de productos | Funcional si la información está incorporada en las páginas |
| Buscador de productos | Prototipo visual hasta implementar y probar su lógica de búsqueda |
| Filtros por precio, equipo y estilo | Prototipo visual hasta implementar y probar los filtros |
| Detalle individual de cada gorra | Funcional si existen páginas de producto con información real |
| Agregar productos a un carrito | Prototipo visual hasta implementar la lógica del carrito |
| Finalización de compras y pagos online | No implementado en esta versión |
| Registro de clientes y suscripción a novedades | Prototipo visual hasta conectar y probar un sistema que almacene los datos |
| Diseño adaptable a celulares, tablets y computadores | Funcional si se implementa y verifica el diseño responsive |

## Integraciones para una versión real

- **Pasarela de pago:** integrar una solución como Mercado Pago o Webpay para permitir pagos online de manera segura.
- **Gestión de productos:** implementar una base de datos o un sistema de administración para actualizar el catálogo, los precios y el stock.
- **Carrito de compras:** desarrollar la lógica necesaria para agregar, eliminar y modificar productos antes de pagar.
- **Gestión de pedidos:** registrar las compras y permitir que el cliente consulte el estado de su pedido.
- **Envíos:** integrar un sistema de cálculo de costos y seguimiento de despachos según la ubicación del comprador.
- **Contacto y atención al cliente:** incorporar un acceso directo a WhatsApp para resolver dudas sobre productos, disponibilidad y compras.
- **Analítica web:** utilizar Google Analytics 4 para medir visitas, productos más vistos, interacciones y conversiones.
- **Captación de clientes:** conectar un formulario de suscripción a una herramienta de email marketing para enviar novedades y lanzamientos.

## Restricciones

- **Plazo:** el desarrollo inicial debe ajustarse al tiempo disponible para completar las entregas académicas. Se priorizará una primera versión visual y navegable antes de incorporar funciones avanzadas.
- **Marca:** altima.str es actualmente un emprendimiento ficticio en etapa de planificación, con proyección de convertirse en un negocio real. La disponibilidad del catálogo, los precios y las condiciones comerciales deberán verificarse antes de vender.
- **Dispositivos:** el sitio debe adaptarse a celulares, tablets y computadores, priorizando la experiencia móvil, ya que el público objetivo utiliza redes sociales y dispositivos móviles para descubrir productos.
- **Presupuesto:** se priorizarán herramientas gratuitas o de bajo costo durante la etapa inicial, evitando gastos innecesarios en servicios que todavía no son indispensables.
- **Limitaciones técnicas:** HTML y CSS permiten construir una interfaz visual, pero no implementan por sí solos un carrito dinámico, pagos online, gestión de inventario ni almacenamiento seguro de datos.
- **Publicación:** GitHub Pages permite alojar un sitio web estático, pero no proporciona por sí solo un servidor backend para procesar pedidos o administrar una tienda online completa.
